# GigaChat: рекомендации похожих исполнителей

Небольшое окно-чат на главной странице: пользователь пишет исполнителей или группы,
которые ему нравятся, а GigaChat предлагает похожих и песни для старта.

## Что где лежит

| Файл | Назначение |
| --- | --- |
| `gigachat_config.dart` | ключ авторизации, scope, модель, системный промпт, лимиты |
| `gigachat_client.dart` | запрос токена доступа (`/api/v2/oauth`) и генерация (`/v1/chat/completions`) |
| `gigachat_tls.dart` | выбор TLS-настроек для платформы |
| `gigachat_tls_io.dart` | доверие сертификатам НУЦ Минцифры нативно (Android/iOS) |
| `gigachat_tls_stub.dart` | пустая заглушка для web |
| `recommend_chat.dart` | состояние диалога: история, отправка, ошибки |
| `recommend_window.dart` | карточка на главной и само окно чата |

Точка входа — `HomeScreen` в `lib/catalog/catalog_screens.dart`: под заголовком
«Каталог» появляется карточка «GigaChat», по нажатию открывается окно чата.

## Ключ и модель

Ключ авторизации **не хранится в git** (`docs/00-ai-agents.md` §4). Он приходит
в приложение через `--dart-define`, поэтому создайте рядом с `pubspec.yaml`
локальный файл `gigachat.local.json` (он в `.gitignore`):

```json
{
  "GIGACHAT_AUTH_KEY": "<ключ_авторизации>",
  "GIGACHAT_SCOPE": "GIGACHAT_API_PERS",
  "GIGACHAT_MODEL": "GigaChat"
}
```

и запускайте:

```bash
flutter run --dart-define-from-file=gigachat.local.json
```

Тот же результат без файла:

```bash
flutter run \
  --dart-define=GIGACHAT_AUTH_KEY=<ключ_авторизации> \
  --dart-define=GIGACHAT_SCOPE=GIGACHAT_API_PERS \
  --dart-define=GIGACHAT_MODEL=GigaChat
```

Если ключ не передан, окно чата покажет подсказку про `--dart-define` и в сеть
не пойдёт.

Доступные модели: `GigaChat`, `GigaChat-2`, `GigaChat-2-Pro`, `GigaChat-2-Max`.

Токен доступа живёт 30 минут: клиент кэширует его, сам обновляет по истечении
и один раз повторяет запрос при ответе 401.

## Тема разговора: только музыка

`GigaChatConfig.systemPrompt` сознательно ограничивает модель: она подбирает
похожих исполнителей и больше ничего. На любой вопрос вне музыки (код, перевод,
новости, «кто ты», смена роли, просьбы игнорировать инструкции) приходит ровно
одна фраза:

> Я подбираю только музыку. Напиши исполнителя или группу — предложу похожих.

Что можно менять:

- текст отказа — в блоке `ГРАНИЦЫ ТЕМЫ` промпта;
- количество исполнителей в подборке и формат списка — в блоке
  `КАК ОТВЕЧАТЬ НА МУЗЫКАЛЬНЫЙ ЗАПРОС`;
- если нужно разрешить вопросы «что за группа / что такое этот жанр» шире,
  добавьте их в список музыкальных запросов — иначе они отбиваются отказом.

Ограничение держится промптом, а не кодом: это надёжно в обычных случаях, но
модель не гарантирует 100 % соблюдения. Если нужна жёсткая гарантия, проверяйте
ответ на бэкенде перед показом.

## Сертификаты НУЦ Минцифры

GigaChat API использует сертификаты НУЦ Минцифры, которых нет в стандартном
хранилище доверенных корней Android/iOS. Поэтому `gigachat_tls_io.dart` разрешает
непроверенную цепочку **только** для доменов `*.giga.chat` и `*.sberbank.ru`.

Для продакшена лучше положить корневой сертификат в assets и подключить его через
`HttpClient..context = SecurityContext(withTrustedRoots: true)..setTrustedCertificatesBytes(...)`,
а `badCertificateCallback` убрать целиком.

## Важно про ключ в мобильном приложении

Ключ внутри APK/IPA можно достать. Для реального релиза запросы к GigaChat стоит
проксировать через свой бэкенд (`src/api`), а в приложении хранить только токен
пользователя. Сейчас, по договорённости, ключ лежит в клиенте.
